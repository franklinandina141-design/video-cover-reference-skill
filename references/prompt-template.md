# 可复用封面提示词

将方括号内容替换为用户实际输入。保留标题的每一个字，不要让模型自行改写。

```text
你是一名短视频封面 art director 和中文标题排版师。根据【人物照片】和【准确标题】制作一张信息流视频封面。

输入图的角色：
- 人物照片：身份与姿态参考，必须保留真实脸部、发型、肤质、服装、动作、手部结构和可见道具。
- 风格参考：使用我提供的参考封面来匹配纸张材质、撕纸边缘、色彩、标题层级、贴纸白边、阴影和手绘装饰，不复制参考图中的人物或文字。

画布：{9:16 竖版 / 16:9 横版 / 4:5}，适合短视频信息流，主体清晰，缩小后仍能读标题。
视觉家族：{黄橙撕纸拼贴 / 宝蓝薄荷绿撕纸拼贴 / 黄黑写实办公}
核心标题（必须逐字保留）：“【准确标题】”
标题排版：把标题拆成 2–4 个有层级的短行；用粗重中文手写刷字或厚重展示体；拼贴家族使用撕纸底、白色贴纸描边和克制的深色阴影，黄黑写实办公家族使用黑色厚阴影/立体偏移；不要使用细字；不要增加、删减或替换文字。

人物：真实立体照片质感，保留自然皮肤、发丝、衣服纹理、手指、透视和光影；人物边缘干净，带自然白色贴纸轮廓与轻微接触阴影；人物不能变成塑料 3D、卡通、扁平贴纸或 AI 换脸。

构图：{根据画幅写出人物位置和标题位置}。人物、标题、道具之间有明显前后层次；标题不能挡住眼睛、脸、手和主要产品；背景留出足够标题空间。

材质与装饰：有真实纤维的米白纸、撕纸边缘、轻微纸张阴影、局部报纸/网格/笔记本碎片、少量手绘星星、灯泡、对话框、箭头、下划线或清单图标；装饰服务于信息层级，不能堆满画面。

色彩：{填写该视觉家族的 palette}。整体明亮、有生活感、色彩明确但不过度荧光。

严格避免：紫黑霓虹科技风、HUD、科幻网格、模板化卡片墙、库存人物、假品牌 logo、错别字、乱码、标题缺字、手指变形、重复手、人物边缘残留门板家具、文字遮脸、过多小字、无意义数据卡。

输出：先生成人物与背景的完整视觉，再用准确文字层完成最终封面；返回一张清晰的最终图片和所用画幅。若模型无法保证中文逐字准确，保留干净的标题区域并在后处理中写入标题。不要自行添加参考图里的英文格言、清单、评论区引导语、期数或其他副标题。
```

## Quick routing examples

- “想做知识科普？”、“小白怎么开始？” → 黄橙撕纸拼贴。
- “AI 工具怎么用？”、“Codex 工作流” → 宝蓝薄荷绿撕纸拼贴。
- “这个产品到底能干什么？”且照片中有手机、电脑或实物演示 → 黄黑写实办公。

用户明确指定风格时，覆盖以上自动路由。
