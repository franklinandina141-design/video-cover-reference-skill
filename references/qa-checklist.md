# 封面交付验收

在返回成品前逐项检查：

- [ ] 标题逐字正确，未丢字、错字、乱码或擅自改写。
- [ ] 主标题在手机信息流缩小后仍清晰，层级只有一个主焦点。
- [ ] 人物身份、脸部比例、发丝、手指、服装和动作可信，没有塑料 3D 或卡通化。
- [ ] 头发、手指、衣服边缘没有门板、椅背、家具或灰色光晕残留。
- [ ] 标题没有压住眼睛、脸、手势或主要产品；人物与纸张有前后层次。
- [ ] 撕纸边缘、纸张纹理、阴影和贴纸白边一致，背景没有无意义的 UI 面板。
- [ ] 选定色彩家族明确：黄橙、蓝绿或黄黑办公，不能互相污染成脏灰色。
- [ ] 所有图标是简洁手绘符号或用户提供的真实素材，不伪造品牌标识。
- [ ] 按用户要求输出 9:16、16:9 或 4:5，并说明实际画幅。
- [ ] 读取返回文件的真实像素尺寸，不把 API 请求尺寸当成已验证尺寸；如用户要求标题在手部上方，标题底边必须高于指尖，且保持可读间距。
- [ ] 标题若包含产品能力或收入/效果承诺，只保留用户原文，不额外夸大。
